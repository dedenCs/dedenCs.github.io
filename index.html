Tentang Saya

Saya adalah seorang pekerja freelance di Shopee sebagai DWR, yang saat ini sedang mengembangkan diri untuk menjadi seorang programmer. Di luar pekerjaan, saya belajar pemrograman secara otodidak dengan berlatih membuat aplikasi berbasis web. Saya mempelajari bagaimana sebuah aplikasi dibangun dari sisi frontend hingga backend, mengelola database, hingga mengembangkan fitur-fitur yang dapat digunakan. Tujuan saya adalah terus berkembang dan mendapatkan kesempatan untuk bekerja sebagai seorang programmer, khususnya di bidang web development.
